# SYN Media Type

Proposed media type:

    application/vnd.syn+json

Recommended filename extension:

    .syn

The extension is part of the SYN product identity, while the media type identifies the document payload. The current browser runtime uses a file picker rather than operating-system file association. Native associations and browser integration are future host/runtime concerns.

The format is currently experimental 0.1 and should not be treated as a frozen Internet standard.
